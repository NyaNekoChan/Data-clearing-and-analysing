# Data-clearing-and-analysing
Очистка данных и небольшой анализ+постоение графика со срезами в Google Sheets
#Данные
  Взяты данные по автомобилям(Цвет, день наблюдения, марка, модель, количество мест)
  Данные имеют пропуски, расхождения в font-е и формате
#Проделано 
  Проведена очистка данных, приведение их к единой структуре, проведён краткий анализ данных, после данные импортированы в csv формат и переведены в сводную таблицу Google Sheets
#Instruments
  Python, numpy, pandas,seaborn,matplotlib, GoogleSheets,JupiterNotebook
